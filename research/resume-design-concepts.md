# Resume Design Concepts — from Adobe Stock research (2026-10-13)

64 structurally distinct concepts. Each is defined by its STRUCTURE and one
signature element — never by color alone. Source patterns: Adobe Stock
top-downloaded resume templates (bold black headers, blue-gray sidebars,
gray+gold executive sets, Memphis illustrations, dark+neon), weandthecolor
template reviews (vertical name + accessory photo, monospace spec labels),
infographic resume practice (KPI cards, timelines, icon grids).

## Formal / editorial
1. broadsheet-executive — newspaper masthead: huge serif name, dateline contact
   line, hairline rules, 2-col experience, small-caps kickers.
2. legal-brief — case-file frame, roman-numeral sections (I. II. III.), dotted
   leaders between role and date, serif.
3. boardroom — centered, wide-tracked small caps, one hairline, huge margins.
4. diplomat — slim centered column, crest-like monogram, formal.
5. ledger — accounting ruled rows, tabular numerals, mono dates.
6. ivory-tower — academic CV: numbered publications, dense serif sections.
7. parliament — strict grid with marginal note column.
8. notary — circular stamp monogram, dotted leaders.

## Sidebar (each a different sidebar idea)
9. dossier — dark sidebar: photo, contact icons, skill meters.
10. rail-timeline — sidebar IS the career timeline.
11. tabbed-sidebar — thick color tabs separating sidebar sections.
12. photo-band — photo fills top 40% of sidebar.
13. index-sidebar — sidebar as numbered book index of sections.
14. dial-sidebar — SVG donut dials for skills in sidebar.
15. profile-card — sidebar as ID card with code block.
16. slim-rail — 180px rail, tiny labels only.

## Timeline
17. metro-map — experience as transit line, stations alternate sides.
18. horizon-band — horizontal career band under header.
19. growth-chart — ascending line with milestone markers.
20. era-blocks — full-width era blocks, giant year numerals.
21. vertical-rail — classic rail with dots (kept only if detailed).
